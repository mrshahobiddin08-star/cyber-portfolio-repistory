# ⚡ Automated Cyberpunk Portfolio Generator

An automated Python tool designed to programmatically generate high-end, cyberpunk-themed presentation slides. This project demonstrates a powerful synergy between **Artificial Intelligence (AI)** image generation and **Python automation** (`python-pptx`) for digital portfolio building.

## 🎨 Visual Identity & Concept
- **Color Palette:** Deep Obsidian Black, Cyberpunk Neon Crimson, and Minimalist Stark White.
- **Theme:** Showcasing a vision of a future where **Advanced Core Programming** and **Global Macroeconomics** intersect via AI Neural Networks.
- **AI Art Generation:** Implemented face-reference algorithms to design futuristic visions (Hacker persona and global publication headlines).

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd cyber-portfolio-repistory
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Generate the PowerPoint presentation (.pptx):**
   ```bash
   python generate_slides.py
   ```

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Automation Engine:** `python-pptx` (PowerPoint Open XML architecture control)
- **Asset Engineering:** Midjourney / DALL-E 3 Face-Mapping Prompts
